# DashBoard
📊 Dashboard UI
This project is a simple and responsive dashboard UI built using HTML & CSS. It features a sidebar navigation menu and a main content area displaying key statistics and visualizations.

✨ Features
✅ Sidebar Navigation – Includes links for 🏠 Home, 📈 Analytics, and ⚙️ Settings.
✅ Dashboard Overview – Displays key statistics like 👥 Total Users, 💰 Sales, and 📊 Revenue.
✅ Data Visualization – Uses 📉 bar charts with trend lines to represent data insights.
